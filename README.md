# Parla — instaladores

Chat de voz y texto P2P para Windows: servers propios, canales, voz con supresión de ruido (RNNoise) y conexión directa entre PCs vía Tailcat.

Este repo solo publica los instaladores. Bajá el último `Parla_*_x64-setup.exe` de [Releases](../../releases/latest) y ejecutalo (no pide admin). La app se actualiza sola desde acá cada vez que se abre.

Componentes de terceros incluidos: ver [THIRD-PARTY.md](THIRD-PARTY.md).
